# Support

## Getting help

Start with the [English documentation](docs/README.en.md) or [Indonesian documentation](docs/README.id.md) for installation, tool setup, usage, and known limitations. Download the app from [GitHub Releases](https://github.com/irfanadwifangga/yt-to-mp3/releases).

Search [existing issues](https://github.com/irfanadwifangga/yt-to-mp3/issues) before opening a new one. If you still need help, open an issue and describe your question and what you have tried. Community support depends on contributor availability; there is no guaranteed response time.

## Choosing where to report

| Situation | Where to go |
| --- | --- |
| Something is broken | Open an issue using the bug report template |
| You have an idea or enhancement | Open an issue using the feature request template |
| You need help using the app | Open an issue with your question and relevant context |
| You want to contribute | Read [CONTRIBUTING.md](CONTRIBUTING.md) |
| You found a security vulnerability | Follow [SECURITY.md](SECURITY.md) and report privately |
| You experienced a conduct violation | Follow the [Code of Conduct](CODE_OF_CONDUCT.md) reporting process |

## Information that helps

Include the app version, operating system and architecture, relevant yt-dlp and FFmpeg versions, steps you tried, and the exact error message. For conversion problems, include the selected format and quality. Screenshots or relevant log excerpts can help; logs are available through the in-app log viewer and in `logs/app.log` under the app data directory described in the documentation.

Before sharing logs or screenshots, remove session tokens, credentials, personal information, and private file paths. Share a public video link only if it is safe to disclose; do not upload private media. Do not post security vulnerability details in a public support issue.
